## ЗАДАНИЕ 3. Разработка фрагмента Руководства оператора
**Цель:** Научиться писать технический текст по правилам: «один шаг – одно действие – один результат», активный залог, строгая терминология.  
**Объём:** 1 страница (текст с нумерацией + блок предупреждения).

**Условие:**  
Напишите фрагмент «Руководства оператора» (И3 по ГОСТ или Руководства пользователя) для роли **Менеджер**.  
**Тема сценария:** «Регистрация входящей заявки по телефону».

**Правила написания (строго соблюдать):**
1. Используйте нумерованный список. Формат: **Шаг → Действие → Результат**.
2. Используйте повелительное наклонение («Нажмите», «Введите»), избегайте слов «необходимо», «следует», «пользователь должен».
3. Используйте термины строго по глоссарию: «Заявка», «Курс», «Карточка клиента» (не используйте слова «лид», «обращение», «звонок»).
4. Добавьте блок ⚠ **Типовая ошибка** с указанием причины и решения.
